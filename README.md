# 🎯 Number Guessing Game

A simple number guessing game made with Python.

The program randomly chooses a number between 1 and 100, and the player has to guess it.

## Features

* Generates a random number
* Takes guesses from the user
* Gives "too high" or "too low" hints
* Counts the number of attempts

## How to Run

Make sure Python is installed.

Then run:

```bash
python number_guessing_game.py
```

## Example

```text
🎯 Number Guessing Game
I'm thinking of a number between 1 and 100.
Enter your guess: 50
Too high!
Enter your guess: 25
Too low!
Enter your guess: 37
🎉 Correct!
You guessed it in 3 attempts.
```
